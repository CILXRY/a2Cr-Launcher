# a2Cr Launcher

这是这个启动器的官方名称。

## `a2Cr` 这个前缀。

无论在什么情况下，都 **不应该** 刻意性的错误标识它的名称，例如：

- 将启动器的大小写错写：`A2cr` `a2CR` `A2cR`
- 修改或删减字符：`aCr` `a@Cr` 等等

`a2cr` 和 `A2CR` 是两种例外情况，当需要全小写/全大写的情况下则不被认为是错误使用。
例如 pyproject.toml 中定义的包名需要全小写时 / 定义环境变量时需要用到全大写时。

## `Launcher` 这个后缀

对于后缀要求并不像 `a2Cr` 作为标识是要求那么严格，
因此无论称呼为：

- `a2Cr Launcher`
- `a2Cr 启动器`
- `a2Cr Launcher 2` （用于区分语言时被认为 C# 版的 a2Cr Launcher）

都没有问题。
