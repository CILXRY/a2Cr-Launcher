## 1. 异常分类

```csharp
LauncherException                  // 基类，全部带可读中文消息
├─ DownloadException               // 下载失败（含失败明细）
├─ AuthException                   // 登录/续期失败
├─ LaunchException                 // 启动失败
│  ├─ MissingFilesException        // classpath 缺文件
│  └─ JavaNotFoundException        // 找不到合适的 Java
├─ PackException                   // 整合包相关
│  ├─ UnsupportedPackException     // 认不出格式
│  └─ PackResolveException         // 清单文件解析不出来
└─ InstanceException               // 实例元数据损坏、目录越界
```

规则：

- 所有异常消息必须是**给用户看的**，能直接进弹窗。技术细节放 `InnerException` 或日志。
- 不允许 `throw new Exception("...")`。
- 不允许把 `OperationCanceledException` 包进上面任何一类。

## 2. 取消语义

| 情形 | 表达 |
|---|---|
| 用户点了取消 | `OperationCanceledException` |
| 超时（网络） | `DownloadException`（是失败，不是取消） |
| 弹窗关闭导致的取消 | 同上，仍按取消处理 |

UI 侧必须这样捕获：

```csharp
catch (OperationCanceledException) when (ct.IsCancellationRequested) { /* 取消，不报错 */ }
```

顺序错了的话，用户点取消会看到"下载失败"的红色弹窗，体验很差。

## 3. 日志

### 3.1 位置

| 日志 | 路径 |
|---|---|
| 启动器 | `logs/launcher/launcher-YYYYMMDD.log` |
| 游戏 | `instances/<folder>/logs/latest.log`（游戏自己写，启动器只读） |
| 崩溃 | `instances/<folder>/crash-reports/` |

### 3.2 规则

- 启动器日志按天分文件，保留 **7 天**，单文件超过 **10 MB** 截断。
- 格式：`时间 [级别] 模块: 消息`，时间用本地时间到秒。
- 级别只用 `Debug / Info / Warn / Error`。正常流程用 Info；可恢复的异常用 Warn；用户操作失败用 Error。
- 必须脱敏：`access_token`、`refresh_token`、`Authorization` 头。
- 日志写入失败（只读盘、占用）不能影响主流程：捕获后静默降级。

### 3.3 分层约束

**Core 里不许出现 `Console.WriteLine` / `Console.Error`。**

v1 在 `core/download.py` 里直接 `print`（连"core 不许 print"这条自己定的规矩都破了）。v2 的做法：

- Core 只暴露 `ILogger` 或回调；
- CLI 把日志写到控制台；
- GUI 把日志写进 `TaskState` / 日志页，并落盘。

这条要写进 `AGENTS.md`，CI 里 grep `Console.Write` 检查 Core 项目。

## 4. 面向用户的错误文案

| 场景 | 文案要求 |
|---|---|
| 网络失败 | 说明"检查网络或代理"，并说明"已下载的文件会保留，重新执行可继续" |
| 找不到 Java | 说明需要哪个大版本（8/17/21），并给出"在设置里手动指定"的入口 |
| classpath 缺文件 | 列出缺几个、是哪个版本，给"重新安装"按钮 |
| 整合包格式不支持 | 列出支持的三类格式 |
| 账号过期 | 说明"已降级为离线启动"，给"重新登录"按钮 |
| 实例元数据损坏 | 指明是哪个文件，说明已按空实例处理，不要直接崩 |

禁止：只显示异常类名、只显示英文、只显示 `NullReferenceException`。

## 5. 崩溃兜底

- 全局未处理异常：写日志 → 显示一个可复制的错误摘要 → 提供"打开日志目录"。
- 不弹 Windows 原始崩溃框。
- 启动阶段（窗口还没起来）的异常：退回到控制台输出 + 退出码 1。
