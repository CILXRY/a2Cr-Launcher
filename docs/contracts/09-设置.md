## 1. 分组

设置项会越加越多，所以从第一天就分组。 **分组按"改它影响什么"来分，不按 UI 页面分**—— 这样加新项时不用纠结放哪。

| 组                        | 影响什么                     | 包含                                                      |
|---------------------------|------------------------------|-----------------------------------------------------------|
| `launch` 启动和实例默认值 | 游戏怎么启动、新实例的默认值 | 内存上限、额外 JVM 参数、新实例语言、启动后是否关闭启动器 |
| `java` Java               | 用哪个 Java                  | 按主版本的路径映射、特殊版本额外路径                      |
| `ui` 启动器显示和外观     | 只影响观感                   | 主题、窗口尺寸、动画开关、语言                            |
| `advanced` Advanced       | 出问题才用                   | 日志级别、日志保留天数、保留原始命令行                    |
| `storage` 存储            | 数据怎么落盘                 | 存档池、去重、实例目录命名风格、回收站保留天数            |
| `download` 下载           | 网络行为                     | 并发、限速、代理、镜像、重试次数                          |

## 2. `launcher.json`

```json
{
  "format": 1,
  "launch": {
    "max_memory": "4G",
    "jvm_args": "",
    "new_instance_language": "inherit",
    "close_after_launch": false
  },
  "java": {
    "overrides": {
      "8": "",
      "17": "",
      "21": "",
      "25": ""
    },
    "extra_paths": []
  },
  "ui": {
    "theme": "system",
    "window_width": 1180,
    "window_height": 760,
    "animations": true,
    "language": "zh-CN"
  },
  "advanced": {
    "log_level": "info",
    "log_keep_days": 7,
    "keep_raw_command_line": false
  },
  "storage": {
    "saves_pool": false,
    "dedup": false,
    "instance_id_style": "slug",
    "trash_keep_days": 30
  },
  "download": {
    "max_concurrency": 8,
    "max_bytes_per_second": 0,
    "proxy": {
      "mode": "system",
      "url": ""
    },
    "mirror_url": "",
    "curseforge_api": "mirror",
    "curseforge_key": "",
    "max_retry": 4
  }
}
```

## 3. 逐项说明

### `launch`

| 键                      | 默认        | 说明                                                                    |
|-------------------------|-------------|-------------------------------------------------------------------------|
| `max_memory`            | `"4G"`      | 只接受 `数字G` / `数字M`；非法值回退默认，不许塞进启动参数              |
| `jvm_args`              | `""`        | 追加到 JVM 参数末尾；按空格切分，**不解析引号**（要引号请写成参数文件） |
| `new_instance_language` | `"inherit"` | 新实例的游戏语言；`inherit` = 跟随启动器语言                            |
| `close_after_launch`    | `false`     | 游戏进程创建成功后关闭启动器                                            |

### `java`

**不设"只有一个 Java 路径"。** 不同版本要不同的 Java（1.8 的整合包要 Java 8， 26.x 要 Java 25），单路径等于每次换版本都手动改。

| 键            | 说明                                                                                     |
|---------------|------------------------------------------------------------------------------------------|
| `overrides`   | 主版本 → 安装目录。空字符串 = 该版本自动发现。键是**字符串**，因为 JSON 的键只能是字符串 |
| `extra_paths` | 额外扫描目录，给非标准位置的发行版（如自编译的 JDK）用                                   |

- 查找顺序：`overrides[主版本]` → 自动发现（见 [`06-启动链路.md`](06-启动链路.md) 第 6 节）。
- `overrides` 里的路径失效时， **报错并提示**，不要悄悄换成自动发现的版本。
- UI 上按主版本列出来（8 / 17 / 21 / 25 …），用户能看到"哪个版本用的是哪个 Java"。

### `ui`

| 键                             | 默认       | 说明                        |
|--------------------------------|------------|-----------------------------|
| `theme`                        | `"system"` | `system` / `dark` / `light` |
| `window_width` `window_height` | 1180 × 760 | 有最小值（960 × 600）       |
| `animations`                   | `true`     | 低配机器或远程桌面可以关掉  |
| `language`                     | `"zh-CN"`  | v2.0 只有中文，字段先留着   |

### `advanced`

| 键                      | 默认     | 说明                                                                                            |
|-------------------------|----------|-------------------------------------------------------------------------------------------------|
| `log_level`             | `"info"` | `error` / `warn` / `info` / `debug`                                                             |
| `log_keep_days`         | `7`      | 启动器自己的日志保留天数                                                                        |
| `keep_raw_command_line` | `false`  | 记录游戏启动命令行。**默认关**：命令行里有 accessToken，开了必须脱敏（见 `08-账号.md` 第 6 节） |

### `storage`

| 键                  | 默认     | 说明                                               |
|---------------------|----------|----------------------------------------------------|
| `saves_pool`        | `false`  | 存档池；关闭时按独占走（见 `02-目录结构.md` 5.4）  |
| `dedup`             | `false`  | 对象库去重，v2.1 才有，v2.0 读到一个 false 就够    |
| `instance_id_style` | `"slug"` | `slug` / `opaque`（见 `02-目录结构.md` 第 4 节）   |
| `trash_keep_days`   | `30`     | 回收站保留天数；到期清理**要用户确认**，不能自动删 |

> "已存储内容的占用分析"不是设置项，是存储组的一个入口/页面：展示逻辑大小、实际占用、
> 去重节省（算法见 `04-文件存储.md` 4.6）。别在 JSON 里给它留字段。

### `download`

| 键                     | 默认       | 说明                                 |
|------------------------|------------|--------------------------------------|
| `max_concurrency`      | `8`        | 1–16                                 |
| `max_bytes_per_second` | `0`        | 0 = 不限速；全局共享额度             |
| `proxy.mode`           | `"system"` | `system` / `custom` / `none`         |
| `proxy.url`            | `""`       | `http://` / `https://` / `socks5://` |
| `mirror_url`           | `""`       | 空 = 直连；填了就是 CDN 镜像前缀     |
| `curseforge_api`       | `"mirror"` | `mirror` / `official`（需 key）/ `off` |
| `curseforge_key`       | `""`       | 用户自己的 CF key；只存本地，不进日志、不上传 |
| `max_retry`            | `4`        | 单文件重试次数                       |

## 4. 规矩

1. **新设置项必须归入上面六组之一**，并在本文表格里加一行。加第七组要先说清它影响什么。
2. **每个值必须有默认值**，且默认值等于"不设置也能正常用"。
3. **未知字段原样保留**（前向兼容）：用户用旧版启动器打开新配置时，不能把新字段抹掉。
4. **写入用临时文件 + 原子替换**，和 `instance.json`、`accounts.json` 一致。
5. **非法值回退默认，不报错也不崩**：设置文件是用户可能手改的东西。
6. **改完立即生效，除非该项明确写了"下次启动生效"**（目前只有 `java.overrides` 需要重开—— 已经在跑的游戏不受影响）。

## 5. 与实例级设置的关系

实例可以覆盖 `launch` 组里的几项（内存、JVM 参数、指定 Java）。规则在
[`03-实例与清单.md`](03-实例与清单.md)： **实例覆盖优先于全局**，实例里没写的项继承全局。 这样"这个整合包要 8G、别的用
4G"不用改全局设置。

## 6. 验收

- 删掉 `launcher.json` → 用默认值正常启动，并重新生成文件。
- 手改一个非法值（`max_memory: "abc"`）→ 回退默认，界面不崩。
- 在文件里塞一个未知字段 → 保存设置后它还在。
- `max_concurrency: 0` 或 `99` → 钳到合法范围（1–16）。
- `java.overrides["21"]` 指向不存在的目录 → 启动该版本时报可读错误。
