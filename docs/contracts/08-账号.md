# 账号

> **完善中**：未定稿，`【待确认】` 处需要拍板；和 [`产品想法.md`](../产品想法.md) 冲突时改本文。

账号是**数据**，不是配置。所有账号信息只存在 `configs/accounts.json`，
`launcher.json`（[`09-设置.md`](09-设置.md)）里最多放一个"默认账号 id"的引用。

## 1. `accounts.json`

```json
{
  "format": 1,
  "active": "a1b2c3",
  "accounts": [
    {
      "id": "a1b2c3",
      "type": "msa",
      "name": "Steve",
      "uuid": "069a79f4-44e9-4726-a5be-fca90e38aaf5",
      "access_token": "…",
      "refresh_token": "…",
      "expires_at": "2026-11-22T03:04:05",
      "xuid": "2535400000000000",
      "client_id": "00000000402b5328"
    },
    {
      "id": "d4e5f6",
      "type": "offline",
      "name": "Alex",
      "uuid": "…"
    }
  ]
}
```

| 字段 | 规则 |
|---|---|
| `format` | schema 版本；遇到更高版本拒绝并提示，不要静默降级 |
| `active` | 当前使用的账号 `id`；找不到就当作未登录，**不要**自动选第一个 |
| `type` | `msa`（正版）/ `offline`（离线） |
| `id` | 本地 id，启动器自己发，和 Mojang 的 uuid 无关（同一个账号重登后 id 不变） |
| `expires_at` | 本地时间 ISO 8601，秒级，**不带时区**（和 `instance.json` 一致） |

读取要求：`utf-8-sig`（兼容记事本 BOM）；JSON 损坏按"没有账号"处理并保留原文件，
不要让界面崩；写入用临时文件 + 原子替换。

## 2. 离线账号

- 玩家名 → uuid 用标准离线算法（`OfflinePlayer:<name>` 的 MD5，并设置版本位），
  保证和主流启动器一致，否则同一个名字在服务器上会被认成不同玩家。
- 名字长度和字符集要校验（Minecraft 用户名 3–16 位，`[A-Za-z0-9_]`），不合法直接拒绝。
- 离线账号没有 token，不参与续期。

## 3. 微软登录（设备代码流程）

不需要回调地址和客户端密钥，适合桌面启动器。步骤（v1 已验证，照搬）：

```text
1. 申请设备码 → 显示 "打开 https://www.microsoft.com/link 输入 XXXX-XXXX"
2. 轮询换取微软 token（间隔取响应里的 interval；收到 slow_down 就 +5s）
3. 微软 token → Xbox Live token → XSTS token → Minecraft access token
4. 用 Minecraft token 拉档案（用户名 / uuid）→ 存成账号
```

错误必须翻译成**人话**，不要把 HTTP 状态码丢给用户。v1 已有一份映射，直接沿用：

| 情况 | 提示 |
|---|---|
| 用户取消授权 | 你取消了对本次登录的授权 |
| 设备码过期 | 设备码已过期，请重新登录 |
| 账号没买 MC / 没建 Xbox 档案（`2148916233`） | 这个微软账号没有 Minecraft，或没有创建 Xbox 档案 |
| 地区不支持（`2148916235`） | Xbox Live 在该国家/地区不可用 |
| 儿童账号（`2148916238`） | 这是儿童账号，需要先加入家庭组 |
| 账号被封（`2148916227`） | 这个账号已被 Xbox Live 封禁 |
| 档案接口 404 | 这个账号没有 Minecraft Java 版 |

## 4. 令牌续期

- Minecraft 的 access token 有效期约 24 小时；**提前 5 分钟**就续期，避免启动瞬间刚好过期。
- 续期失败（refresh token 失效）时：提示"登录已过期，请重新登录"，
  **保留账号条目**（名字还在），只把 token 清空并标记需要重登。不要静默删号。
- 续期发生在"启动游戏前"和"界面需要显示账号信息时"，不要在后台无限轮询。

## 5. 多账号

- 支持多个账号，`active` 指定当前用的那个。
- 启动时可以临时指定用哪个账号（CLI `--account`，GUI 在启动按钮旁选），
  这种临时指定**不改变** `active`。
- 退出登录 = 从 `accounts` 里删掉该条目；如果删的是 `active`，`active` 置空。

## 6. 安全

- **token 明文存储**（已定的决策）：用户会把数据目录整体拷贝到别的机器，加密后跨机全失效。
- **token 会出现在游戏进程的命令行里**——这是 Minecraft 的要求（`--accessToken`），
  躲不掉。所以：
  - 日志里**绝不能**打印完整命令行或 token；
  - "保留原始命令行"（[`09-设置.md`](09-设置.md) 的高级组）默认**关闭**；
  - 即使开启，落盘前也必须把 `--accessToken`、`--uuid` 之类的值替换成 `***`。
- 界面上的"查看即将执行的命令"要同样脱敏。

## 7. 不做

- 不存微软账号密码，不做"记住密码"。
- 不做第三方皮肤站登录（Mojang 的 profile 已包含皮肤）。
- 不做账号分享 / 令牌同步。

## 8. 验收

- 设备码登录成功一次，重启启动器后账号仍在且能直接启动。
- 断网时启动：用缓存里的 token 启动，失败要给可读提示，不能卡住。
- refresh token 失效：提示重新登录，账号条目还在。
- 离线账号名重复 → 生成同一个 uuid，服务器认成同一个玩家。
- 日志和"查看命令行"里搜不到完整 token。
