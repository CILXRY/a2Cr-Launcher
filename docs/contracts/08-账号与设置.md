## 1. `configs/accounts.json`

多账号。不兼容 v1 的 `auth.json`，不做读取迁移。

```json
{
  "format": 1,
  "selected": "069a79f4-44e9-4726-a5be-fca90e38aaf5",
  "accounts": [
    {
      "id": "069a79f4-44e9-4726-a5be-fca90e38aaf5",
      "kind": "microsoft",
      "name": "Steve",
      "uuid": "069a79f4-44e9-4726-a5be-fca90e38aaf5",
      "access_token": "…",
      "expires_at": "2026-11-21T03:04:05",
      "refresh_token": "…",
      "xuid": "…",
      "client_id": "00000000402b5328",
      "added_at": "2026-11-20T03:04:05"
    },
    { "id": "1b2c…", "kind": "offline", "name": "TestUser", "uuid": "1b2c…", "added_at": "…" }
  ]
}
```

| 字段 | 规则 |
|---|---|
| `id` | 在线账号 = UUID；离线账号 = 派生 UUID。账号唯一标识 |
| `kind` | `microsoft` / `offline` |
| `selected` | 当前使用账号的 `id`；指向不存在的账号时视为无选中 |
| `expires_at` | 本地时间 ISO 8601；只对在线账号有意义 |
| 写入 | 临时文件 + 原子替换；写入前 `mkdir -p` |

### 离线 UUID

必须与 Minecraft 一致，否则存档里的玩家数据会对不上：

```text
UUID = UUIDv3( MD5("OfflinePlayer:" + name) )，设置 version=3、variant=RFC4122
```

.NET 没有现成的 UUIDv3，需要手写（MD5 后改第 6、8 字节）。这条要有单测，用已知的 name→uuid 对照。

## 2. Token 策略

- 启动前检查：`expires_at - 5 分钟 < now` 才刷新，避免刚好在启动瞬间过期。
- 刷新失败**不阻断启动**：降级为离线身份，并在 UI 明确提示"正版登录已失效，请重新登录"。不要静默吞掉（v1 就是静默吞掉的，用户完全不知道）。
- `refresh_token` 明文存储。**不要**加 DPAPI：用户会把整个数据目录拷到另一台机器，加了就全废。要加密是另一个功能，必须带无密钥回退。
- `access_token` / `refresh_token` **禁止**出现在任何日志、异常消息、崩溃报告、CLI 输出里。序列化时对这两个字段做脱敏。

### 必须存在的回归测试

v1 有一个真实缺陷：GUI 启动时没有把账号传进参数拼装，导致"登录了但游戏是离线身份，进不了正版服务器"。

v2 必须有这条测试：**选中在线账号启动 → 生成的 argv 里出现真实 UUID 与 access token，且 `user_type == "msa"`**。

## 3. 微软登录（设备代码流程）

| 步骤 | 地址 |
|---|---|
| 申请设备码 | `POST https://login.live.com/oauth20_connect.srf` |
| 轮询 token | `POST https://login.live.com/oauth20_token.srf` |
| Xbox 认证 | `POST https://user.auth.xboxlive.com/user/authenticate` |
| XSTS 授权 | `POST https://xsts.auth.xboxlive.com/xsts/authorize` |
| Minecraft 登录 | `POST https://api.minecraftservices.com/authentication/login_with_xbox` |
| 档案 | `GET https://api.minecraftservices.com/minecraft/profile` |

- `client_id = 00000000402b5328`（公共客户端，无 secret）
- `scope = service::user.auth.xboxlive.com::MBI_SSL`
- `RelyingParty`：Xbox 用 `http://auth.xboxlive.com`，XSTS 用 `rp://api.minecraftservices.com/`
- XSTS 的 `identityToken` 格式：`XBL3.0 x=<uhs>;<token>`

轮询错误码：

| code | 处理 |
|---|---|
| `authorization_pending` | 继续等 |
| `slow_down` | 间隔 +5s 继续 |
| `expired_token` | 提示设备码过期，重新发起 |
| `authorization_declined` / `access_denied` | 提示用户取消了授权 |
| 其它 | 展示 `error_description` |

XSTS 错误码（要保留中文文案）：

| code | 文案 |
|---|---|
| `2148916233` | 这个微软账号没有购买 Minecraft（或没有创建 Xbox 档案） |
| `2148916235` | Xbox Live 在所在国家/地区不可用 |
| `2148916238` | 这是儿童账号，需要先加入家庭组 |
| `2148916227` | 这个账号已被 Xbox Live 封禁 |

UI 要能显示设备码 + 链接 `https://www.microsoft.com/link`，并提供"复制"按钮。

## 4. 头像

- 地址：`https://mc-heads.net/avatar/{uuid}/64`（备用 `https://crafatar.com/avatars/{uuid}?size=64`）
- 缓存到 `shared/cache/icons/<sha1>.<ext>`，7 天过期。
- 取不到就用本地占位图，**不要**让账号列表因为网络失败变空白。

## 5. `configs/launcher.json`

```json
{
  "format": 1,
  "defaults_profile": "new",
  "player_name": "a2Cr",
  "max_memory": "4G",
  "java_path": "",
  "theme": "dark",
  "language": "zh-CN",
  "instance_id_style": "slug",
  "last_instance": "",
  "window_width": 1180,
  "window_height": 760,
  "close_on_launch": false,
  "show_snapshots": false,
  "dedupe_enabled": true,
  "sync_enabled": false,
  "sync_groups": []
}
```

### 归一化（是行为，不是格式）

- 只接受上表这些键；未知键保存时丢弃。新增字段必须同时改默认表。
- `max_memory`：`^\d+[GM]$`；`M` 小于 512 视为无效；无效回落 `4G`。
- `theme` 不在 `dark|light|system` → `dark`。
- `window_width ≥ 960`、`window_height ≥ 640`；转换失败用默认值。
- `player_name` 去空白后为空 → `a2Cr`。
- `instance_id_style` 不在 `slug|opaque` → `slug`。
- 文件损坏 / 无权限 → 返回默认值，**不许让窗口起不来**（v1 issue #4 的教训）。

### `defaults_profile`

决定"去重 / 同步"的默认开关，只在**首次运行**判定一次：

```text
configs/launcher.json 不存在，且根目录下存在 v1 的 settings.json  →  "legacy"
否则                                                             →  "new"
```

| profile | `dedupe_enabled` 默认 | `sync_enabled` 默认 |
|---|---|---|
| `new` | true | false |
| `legacy` | false | false |

判定只影响默认值，**不读取 v1 的任何数据**。

## 6. 设置项含义

| 键 | UI | 说明 |
|---|---|---|
| `player_name` | 设置页 | 离线账号的默认名字 |
| `max_memory` | 设置页 | `-Xmx` |
| `java_path` | 设置页 | 空 = 自动发现 |
| `theme` | 外观 | 跟随系统用 `system` |
| `language` | 外观 | v2.0 只有 `zh-CN`，字段先留着 |
| `instance_id_style` | 高级 | 只影响新建实例 |
| `last_instance` | 隐式 | 首页默认选中的实例 |
| `close_on_launch` | 设置页 | 启动游戏后关闭启动器 |
| `show_snapshots` | 版本页 | 是否显示快照 |
| `dedupe_enabled` | 高级 | v2.1 生效 |
| `sync_enabled` | 设置页 | v2.2 生效 |

## 7. 测试点

- 已知 name → offline uuid 与官方一致。
- v1 缺陷回归：在线账号启动时 argv 带真实 token。
- token 不出现在日志里（用一个检测 token 字符串的测试）。
- `launcher.json` 损坏 → 启动不崩，使用默认值。
- 刷新失败 → 降级为离线且能启动。
