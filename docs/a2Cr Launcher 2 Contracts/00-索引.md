# a2Cr Launcher 2 · 契约索引

这套文档是 v2（C# / Avalonia）的**唯一事实来源**。
`docs/CONTRACT.md` 描述的是 v1（Python）的实现，只作历史参考，不再作为依据。

## 拆分原则

一份文档只管一件事。改某一块的时候只动对应的文件，不要往别的文件里顺手加。
每次改动都要在 `11-决策记录.md` 里补一行，说明**为什么改**。

| 文件 | 管什么 | 什么时候改 |
|---|---|---|
| `01-目录结构.md` | 磁盘布局、实例命名、根目录覆盖 | 增删顶层目录、改命名策略 |
| `02-实例与清单.md` | `instance.json`、`manifest.json`、克隆、模板应用、回收站 | 改实例元数据或文件归属规则 |
| `03-文件存储.md` | 写文件唯一入口、对象库、去重、GC、只读 | 改存储机制 |
| `04-下载与进度.md` | 续传、重试、进度回调、取消 | 改下载行为 |
| `05-启动链路.md` | 版本 JSON、合并、规则、参数、Java、进程 | 改启动逻辑 |
| `06-整合包与搜索.md` | provider 抽象、Modrinth、CurseForge、导入阶段 | 接新内容源或改导入流程 |
| `07-账号与设置.md` | `accounts.json`、微软登录、`launcher.json` | 改账号模型或设置项 |
| `08-CLI.md` | 命令集、退出码 | 增删命令或参数 |
| `09-错误与日志.md` | 异常分类、取消语义、日志落盘 | 改错误处理/日志策略 |
| `10-验收与回归.md` | Golden 数据、真实回归清单、CI 检查 | 每次发布前对照 |
| `11-决策记录.md` | 设计决策流水账 | 每次做取舍 |

## 三条铁律

1. **实现与文档冲突时改实现**。要改文档，先在 `11-决策记录.md` 写一条，再说服另一位。
2. **不兼容 v1**。v2 不读 `~/.a2CrLauncher` 下的任何旧文件。唯一的例外是首次运行时探测旧目录是否存在，用来决定 `defaults_profile`（见 `07-账号与设置.md`）。
3. **一处分层，全局生效**。凡是"不许直接做"的规矩（比如 core 不许写文件、不许打日志），写入 `AGENTS.md`，而不是散落在各文档里。

## 版本范围

| 阶段 | 范围 |
|---|---|
| **v2.0** | 原版安装/启动、Fabric/Quilt/Forge/NeoForge、整合包导入、Modrinth 搜索、多账号、CLI、Avalonia 界面 |
| **v2.1** | 对象库去重（`shared/objects` + 硬链接）、GC、存储占用页 |
| **v2.2** | 跨实例同步（options 字段合并、servers/config 整文件、mod 集合） |

`03-文件存储.md` 里描述的对象库是 v2.1 的**设计定稿**，v2.0 只实现它的接口壳。

## 术语

| 术语 | 含义 |
|---|---|
| 实例（instance） | `instances/<folder>/`，一个完整的游戏目录 |
| 清单（manifest） | 实例内 `manifest.json`，记录每个文件的来源与哈希 |
| 对象（object） | `shared/objects/<sha1>`，按内容寻址的唯一物理副本 |
| 模板（template） | `templates/<id>/`，新建实例时的默认文件来源 |
| 兼容组 | `(mc_version, loader, loader_version)` 相同的一组实例；同步只在组内进行 |
| 同步组 | v2.2 概念：多个实例共享一份可变文件（如 `options.txt` 的某些字段） |
