# C# 的开发环境配置（v2）

v2 用 **C# + Avalonia**。这份说明只保证你能把项目跑起来，不教语言本身——语言在 [学习笔记](../learning/第01课-CSharp词表.md)。

## 1. 装 .NET SDK

去 [.NET 官网](https://dotnet.microsoft.com/download) 下载 **LTS 版本**（偶数版本，当前是 .NET 10；具体以官网为准）。

装完开一个**新**终端验证：

```powershell
dotnet --version        # 能打印版本号
dotnet --list-sdks      # 列出已装的 SDK
```

> 预览版（preview / RC）不要用。你在学语言，不该同时给运行时当小白鼠。

## 2. 装 IDE

三个都行，按习惯选一个：

| 工具 | 说明 |
|---|---|
| [JetBrains Rider](https://www.jetbrains.com/rider/) | 对 C# / Avalonia 支持最好；非商业用途可申请免费授权 |
| [Visual Studio](https://visualstudio.microsoft.com/) | 装 "**.NET 桌面开发**" 工作负载 |
| [VS Code](https://code.visualstudio.com/) + **C# Dev Kit** 扩展 | 最轻，但对 XAML 的支持弱一些 |

## 3. 装 Avalonia 模板

Avalonia 不是 .NET 自带的，需要装一次模板：

```powershell
dotnet new install Avalonia.Templates
```

验证：

```powershell
dotnet new list avalonia    # 能列出 avalonia.app / avalonia.mvvm 等模板
```

## 4. 先用一个临时项目试手

不要在正式仓库里试。找个空目录：

```powershell
dotnet new avalonia.app -o Playground
cd Playground
dotnet run
```

能弹出窗口就说明环境完全没问题。**这一步跑通之前别动本仓库。**

## 5. 在仓库里建项目（v2 开工时才需要）

仓库规划的结构：

```text
src/
├─a2Cr.Core/        ← 核心逻辑，不许引用 UI
├─a2Cr.Cli/         ← 命令行入口，跑回归用
└─a2Cr.app/         ← Avalonia 界面
tests/
└─a2Cr.Core.Tests/  ← 单元测试
```

对应的命令：

```powershell
dotnet new sln -n a2Cr -o src
dotnet new classlib  -o src/a2Cr.Core   -n a2Cr.Core
dotnet new console   -o src/a2Cr.Cli    -n a2Cr.Cli
dotnet new avalonia.app -o src/a2Cr.app -n a2Cr.App
dotnet new xunit     -o tests/a2Cr.Core.Tests -n a2Cr.Core.Tests
```

## 6. 几个会浪费你半天的坑

- **`bin/` `obj/` 不要提交**。仓库的 `.gitignore` 已经挡住了；如果 `git status` 里还出现它们，说明你在别的目录建了项目。
- **中文路径 + 深层目录**可能撞 260 字符上限。仓库放在 `Documents` 下面没问题，实例目录由启动器自己处理长路径。
- **SDK 版本不一致**：团队成员 SDK 不同时，用 `global.json` 锁定版本。
- **改了 `.csproj` 之后一定要重新 `dotnet restore`**，否则报的错会跟真实原因完全无关。
