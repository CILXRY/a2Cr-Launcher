## 任务怎么写

不好的任务：**"把整合包导入做得稳一点"**

好的任务包含四样：

```text
目标：导入 mrpack 时，若实例目录已存在则跳过已下载文件，不重复下载
涉及：src/a2Cr.Core/Modpack/
不要动：Download/（接口已冻结）
验收：
  1. a2Cr import X.mrpack 跑两次
  2. 第二次日志里全是 skipped，不产生网络请求
  3. 实例目录内容不变
```

**"正确"必须是可验证的。** 给不出验收命令，就说明任务还没想清楚。
